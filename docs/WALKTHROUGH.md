# 从公开历史记录到预测、校准与订货

本文连接45店四步预测与M5商品门店订货两条分析线。两者使用不同数据粒度、模型和单位，先分别走完，再理解它们的关系。

## 1. 45店：过去12周是什么样

选取公开Walmart数据中门店1、2012-03-02开始的四周测试样本。六个历史输入分别为销售额、节假日、温度、油价、CPI和失业率。
下表列出该输入窗口的12周销售额；模型还同时读取其余五列。

| 历史周 | 周销售额（美元） |
|---|---:|
| 2011-12-09 | 1,799,682.38 |
| 2011-12-16 | 1,881,176.67 |
| 2011-12-23 | 2,270,188.99 |
| 2011-12-30 | 1,497,462.72 |
| 2012-01-06 | 1,550,369.92 |
| 2012-01-13 | 1,459,601.17 |
| 2012-01-20 | 1,394,393.84 |
| 2012-01-27 | 1,319,325.59 |
| 2012-02-03 | 1,636,339.65 |
| 2012-02-10 | 1,802,477.43 |
| 2012-02-17 | 1,819,870.00 |
| 2012-02-24 | 1,539,387.83 |

12周×6列是一张12×6的小表。把许多门店和起点的小表叠在一起，才组成训练输入张量。
输入截止2012-02-24，四个目标周从2012-03-02开始。`build_windows` 构造窗口，`split_by_target_dates` 确认整个目标窗口属于测试期。

## 2. 标准化与还原不是重新预测

目标缩放只用训练区，均值约 **1,035,944.31美元**，标准差约 **559,563.06美元**。
缩放为“原金额减均值，再除标准差”；还原为“缩放值乘标准差，再加均值”。输入六列另有自己的训练期均值与标准差。

保存的Attention预测文件给出该样本的四个缩放值。还原后：

| 目标周 | 保存预测（缩放值） | 预测销售额（美元） | 公开数据实际销售额（美元） |
|---|---:|---:|---:|
| 2012-03-02 | 0.994926 | 1,592,668.12 | 1,688,420.76 |
| 2012-03-09 | 0.945676 | 1,565,109.50 | 1,675,431.16 |
| 2012-03-16 | 0.941338 | 1,562,682.25 | 1,677,472.78 |
| 2012-03-23 | 0.924699 | 1,553,371.62 | 1,511,068.07 |

对应文件为 `results/lstm_pred_lstm_attention.npy`，对应模型在 `scripts/train_lstm_forecast.py` 的 `Forecaster`。
LSTM先压缩历史变化，Attention再在历史表示之间分配权重，输出层一次给出四个点预测。

## 3. 为什么还要做简单基准

naive把输入末周 **1,539,387.83美元**重复四次；MA4把输入末四周平均 **1,699,518.73美元**重复四次。
它们和模型都不能读取表里的实际未来销售额。比较时，对同一个目标求绝对误差，再汇总同一批1,440个起点和四个步长。
一个样本不能证明某个模型更好；整体MAE和五折回测分别回答平均精度与窗口稳定性。

## 4. M5：把对象换成一个商品门店

选取 `m5/results/quantile_predictions.csv` 的样本 `FOODS_2_331_CA_1_validation`，零售周从 `2015-10-24` 开始，至下周五结束。
这个周上周销量naive为 **12件**，测试销量为 **3件**，价格 **2.50美元/件**。

处理链是：日销量按日历周编号求和 → 按门店/商品/零售周接价格 → 用shift构造过去销量 → LightGBM预测相对naive的残差。
概率模型另在proper区训练，P50为 **7.2701件**，P10与P90分别为 **3.5091、11.8844件**。
它不等于点预测脚本的独立残差模型，二者训练任务和可用训练区不同。

## 5. 区间校准在调整什么

16周校准期的区间分数决定调整量，当前为约1.24245件。
本样本校准后的80%范围是 **2.2666至13.1269件**，实际3件落在其中。
整批2,600条记录逐条检查才得到80.8%的经验覆盖；这个比例不是模型给每条记录单独报出的置信度。

## 6. 订货校准单独算，不使用区间宽度

缺货系数0.30、积压系数0.25，临界分位为0.54545。
从该商品门店16个校准期P50残差中取第10个排序值，给本样本加上约 **2.9385件**余量，得到Q。
此处使用保存的非负连续订货量，尚未加入整数箱规；若要按整箱订货，需要另作离线情景比较。

| 方法 | 保存订货量Q（件） | 本样本费用（美元） |
|---|---:|---:|
| naive+校准 | 13.0000 | 6.2500 |
| P50+校准 | 10.2086 | 4.5054 |
| naive+正态 | 12.7703 | 6.1064 |

在这个样本中Q高于实际销量，只计算多备部分费用；Q低于实际时则计算少备部分费用。对整批测试样本分别求平均，才得到13.2804与14.6468美元/商品门店周的比较，单条费用不能代替整体降幅。

## 7. 自己核对一行，不需要重新训练

从仓库根目录执行：

```python
import csv

with open('m5/results/quantile_predictions.csv', encoding='utf-8') as f:
    r = next(csv.DictReader(f))
y, q, p = float(r['actual']), float(r['order_model']), float(r['price'])
cost = p * (0.30 * max(y-q, 0) + 0.25 * max(q-y, 0))
print(r['id'], r['week_start'], q, cost)
```

`python scripts/verify_results.py` 会对保存的全部预测与订货量执行核对；正式训练命令另见README。
