# M5 概率订货六折回测

每折仅用校准开始前的历史销量选取100条商品门店序列，同一历史区拟合P10、P50、P90三个LightGBM，每个模型700棵树，种子42。随后用独立16周校准，再评估26周。六个测试窗互不重叠，每个窗口每周预测下一周，已发生的前几周销量可以成为后续预测的滞后特征。设定在预测时已知目标零售周的价格、节日和日历字段。最后不足七天的零售周排除。

区间用校准期P10/P90的误差分数调整上下界。订货另用每条序列的P50或上周值残差，在同一校准期按缺货与积压系数取第10个残差次序统计量。各策略的订货量统一截到零。按当周价格、实际销量和缺货/积压系数0.30/0.25结算单周期费用，单位为美元/商品门店周。

合并口径为全部15,600条配对测试记录的总费用除以记录数，降幅用两套策略的总费用计算。每折原始及有效测试行数均为2,600，校准共9,600行。P50+校准6折费用都更低，第5折只低0.22%。它的合并需求量满足率为91.74%，上周值+校准为90.80%，同时发生过缺货的记录占比由35.69%升到38.27%。这两项结果分别反映一共满足多少件和有多少条记录出现缺口，适用于不同服务目标。以正态近似校准上周值的第三套策略合并费用为 $11.9528。

原始P10/P50/P90出现1,112次交叉，经现有池化分数调整后，P10/P90测试区间无倒置。合并覆盖为80.04%，各折为77.38%至82.77%。覆盖与宽度均在这批时间相关的面板记录上计算，适用范围限于实验样本。每折从当时历史重新选样，商品组合会变。费用来自公开销量和预设系数，按单周期计算。

## 复现和逐行核对

在仓库根目录执行：

```bash
python m5/scripts/probabilistic_backtest.py --data-dir m5/data
python m5/scripts/probabilistic_backtest.py --verify
```

`--outdir` 可给重跑指定一个输出目录。结果目录保存训练/选样/校准/测试日期、样本量、数据指纹和依赖版本，以及校准原始分位数、逐行测试预测、每个策略的非负订货量、缺口与费用。校验命令从行级校准证据重建区间、订货与汇总，训练命令重新拟合18个分位模型。
